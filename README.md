## ✨ Deneyim

- Kaydırdıkça yumuşakça açılan sahneler ve metinler
- Sinematik ışık, paralaks ve parçacık efektleri
- Cumhuriyet tarihini anlatan görsel zaman çizgisi
- Telefon ve masaüstüne uyumlu tasarım

## 🚀 Çalıştır

Projeyi indir ve `index.html` dosyasını tarayıcıda aç. Yerel sunucu kullanmak için proje klasöründe:

```bash
py -m http.server 8000
```

Ardından `http://localhost:8000` adresini aç.

## 📁 Yapı

```text
├── index.html
├── css/style.css
├── js/main.js
└── assets/images/
```

## 🌐 GitHub Pages

Depoda **Settings → Pages** bölümünü aç; `main` dalını ve `/ (root)` klasörünü seç.
